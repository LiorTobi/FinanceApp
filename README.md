# הכסף שלי

אפליקציית PWA אישית לניהול הכנסות והוצאות בעברית. כל המידע נשמר מקומית ב־IndexedDB בדפדפן, ללא שרת, חשבון משתמש או שירות חיצוני.

## הרצה מקומית

יש להגיש את התיקייה באמצעות שרת HTTP מקומי (לא באמצעות `file://`). לדוגמה, אם Python כבר מותקן:

```powershell
python -m http.server 8080
```

לאחר מכן פותחים `http://localhost:8080`. יכולות PWA מלאות והתקנה דורשות HTTPS בפרסום קבוע (או `localhost` לצורכי פיתוח).

## פרטיות וגיבוי

הנתונים אינם יוצאים מהמכשיר. ניקוי נתוני האתר, הסרת האפליקציה או אובדן המכשיר עלולים למחוק אותם, ולכן מומלץ לייצא גיבוי JSON באופן קבוע מההגדרות.
